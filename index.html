📥 Import เครื่องจักรจาก JSON

อัปโหลดไฟล์ .json ที่มีข้อมูลเครื่องจักร + STD (รูปแบบเดียวกับ config ที่ระบบใช้อยู่) เพื่อนำเข้าทีเดียวหลายเครื่อง แทนการกรอกทีละเครื่องด้านล่าง
โครงสร้างไฟล์ต้องเป็น array ของ object เครื่องจักร แต่ละตัวมี field: family, customer, model, machine_no, part_no, part_name, rank, doc_no, run_no, rev_no, rev_date, issue_form_date, config — field config ต้องตรงรูปแบบตาม family นั้นๆ (ดูตัวอย่างในปุ่ม "ดู JSON ตัวอย่าง" ด้านล่าง)

เพิ่มเครื่องจักร / Part ใหม่

ตั้งค่าเครื่องจักร (Config)
